# Machine Learning
Machine learning is a branch of AI that is used  to make ai models that learn from data. 

## Types of models we can make by machine learning:
1. Numerical data Classification models
2. Regression models
3. Image/video classification models
4. Image/video generation models
5. LLMs

### Supervised Learning 
Supervised Learning is a type of machine learning in which the model is trained on a data with the output given with input and model uses mathematical algorithms to find patterns in inputs and their respective outputs.
